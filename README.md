# DDL Data

Public repo storing info for the [Denouement Demon List](https://www.denouementdemonlist.com). The site reads these files directly and they are updated automatically whenever the list changes.

| File | Contents |
| --- | --- |
| `<list>/levels.json` | Levels in rank order, without records |
| `<list>/levels-full.json` | Levels in rank order, with records |
| `<list>/packs.json` | Packs |
| `<list>/rules.json` | Rules |
| `editors.json` | List staff |

`<list>` is `DDL`, `DCL` or `DVL`.
